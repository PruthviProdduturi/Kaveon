# Iceberg reader qualification — local stack, 2026-09-21

An Iceberg v2 table written by pyiceberg 0.12 (`scripts/make-iceberg-fixture.py
tmp/kaveon-events --as /data`: two appends and a delete of one region, three
snapshots, four data files, 187,275 rows kept) and its Parquet twin (the same
rows, written from the table's current snapshot), both registered on the
Compose stack's Engine (`kaveon.qualification.iceberg_twin` at the last
metadata JSON, `kaveon.qualification.parquet_twin`), then the same seven
statements run over each with `use_statistics = false` and
`result_cache = false`.

| Statement | Iceberg | Parquet | Agree |
|---|---:|---:|---|
| `COUNT(*)` | 187,275 | 187,275 | yes |
| `GROUP BY region`: count, `SUM(amount)`, `MIN(day)`, `MAX(day)` | 3 rows | 3 rows | counts, mins, maxes exact; `SUM` differs in the 9th significant digit (floating-point summation order over different file splits) |
| `COUNT(*) WHERE amount IS NULL` | 9,233 | 9,233 | yes |
| `GROUP BY platform WHERE day >= DATE '2026-03-01' AND active` | 3 rows | 3 rows | yes |
| `COUNT(DISTINCT region), COUNT(DISTINCT platform)` | 3, 3 | 3, 3 | yes |
| `ORDER BY amount DESC, id LIMIT 5` | 5 rows | 5 rows | yes |
| `COUNT(*) WHERE region = 'latam'` (the deleted region) | 0 | 0 | yes — the snapshot's delete is honoured |

Elapsed on the local stack (one coordinator, two workers, not a
measurement): Iceberg 37–162 ms, Parquet 10–89 ms per statement; the
Iceberg side reads the metadata pointer and two manifest lists per query.

What this establishes: the Engine reads an Iceberg v2 table's current
snapshot correctly through a metadata JSON pointer on local storage —
schema by field id, manifest status (the deleted files are not read), typed
predicates and dates. What it does not: ADLS Gen2 (the same object-store
code path as the qualified Delta reads, but not yet run against a table on
the cluster), v1 tables, position/equality deletes carried as delete
files (pyiceberg's `delete` rewrote the affected data files here),
schema evolution across snapshots, snapshot selection other than current.
